# TEST_MAKE - STM32F103 嵌入式测试工程

## 项目简介

基于 **STM32F103**，使用 STM32CubeMX + HAL库 + CMake 构建的底层调试测试工程
实现功能：USB虚拟串口CDC日志输出、正交编码器数值采集、按键检测、LED翻转指示、简易状态机框架

## 硬件资源分配

| 外设 | 对应资源 | 用途 |
| ---- | -------- | ---- |
| LED1 | GPIO | 状态翻转指示灯 |
| DI_KEY | 输入引脚 | 按键触发清零/赋值计数 |
| TIM3 | 定时器正交编码器模式 | 旋转编码器脉冲采集 |
| USB_DEVICE | USB FS | CDC虚拟串口，打印调试日志 |

## 开发环境

- IDE：VSCode + CMake + Ninja
- 固件库：STM32F1xx HAL Driver
- 编译工具：ARM GCC 交叉编译器
- 烧录调试：DAPLink + OpenOCD
- 上位机：串口工具接收CDC打印数据


## 现有功能说明

1. **LED闪烁上报**：LED电平翻转时，USB串口推送LED开关状态日志
2. **按键检测**：按键按下，强制设置计数 = 5000，同时清零TIM3编码器硬件计数器
3. **旋转编码器**：采集TIM3脉冲，软件分频换算数值，转动实时串口打印数值
4. **USB CDC收发**：带超时机制的串口发送函数，防止USB忙等待卡死

## 编译 & 烧录步骤

1. CubeMX 改动配置后重新生成代码
2. VSCode加载CMake项目，执行编译构建
3. DAPLink连接开发板调试接口
4. OpenOCD下载固件至芯片Flash并运行
5. 电脑打开串口工具，即可接收所有打印日志

## 关键函数说明

- `CDC_Send()`：带超时的USB串口发送接口
- `led_toggle()`：LED翻转+串口日志输出
- `DI_KEY_check()`：按键捕获处理
- `digit_encoder_check()`：TIM3编码器数值读取、换算、上报
